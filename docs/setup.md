1. Open the app and log in as Citizen.
2. Turn on airplane mode (mobile) or DevTools → Network → Offline (browser).
3. Submit a report — it should queue locally rather than fail.
4. Reconnect — the queued report should sync automatically and appear in the correct staff queue.
